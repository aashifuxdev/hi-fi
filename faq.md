# FAQ

<details>

<summary>What do I need to run Hi-Fi?</summary>

Node.js 18 or later and npm. See [Getting Started](sample.md).

</details>

<details>

<summary>Can I use Yarn or pnpm instead of npm?</summary>

Yes. Replace `npm install` with `yarn` or `pnpm install`.

</details>

<details>

<summary>Where do I change the API URL?</summary>

Set `API_URL` in your `.env` file. See [Configuration](configuration.md).

</details>

<details>

<summary>Does Hi-Fi support dark mode?</summary>

Yes. All [components](components.md) support light and dark themes.

</details>

<details>

<summary>How do I report a bug?</summary>

Open an issue on the GitHub repository with steps to reproduce it.

</details>
